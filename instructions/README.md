# Инструкции агентам

Last Updated: 2026-10-30

AGENTS.md — универсальная версия рабочих правил. Для всех проектов объедините
её с существующим AGENTS.md в data directory из bb status. Для одного проекта
BB читает .bb/AGENTS.md в корне репозитория. Не заменяйте существующие правила
вслепую: это редактируемый образец, правила вашего проекта важнее. Проверьте
применение в новом треде.
