# Баланс счёта Яндекса в «Стороже лимитов» — сервисный аккаунт только для чтения

Last Updated: 2026-11-21

Баланс — поле `balance` ответа `GET https://billing.api.cloud.yandex.net/billing/v1/billingAccounts/{id}`; ключ от AI Studio
для него не годится. Нужен сервисный аккаунт с ролью `billing.accounts.viewer` (только чтение платёжного аккаунта) и его
**авторизованный ключ** (JSON). Больше он ничего не может: ни платить, ни менять, ни вызывать модели.

## Шаги в консоли Яндекса (https://console.yandex.cloud, интерфейс на английском)

1. **Service accounts → Create service account**: имя `limit-guard-billing`, роли в каталоге не назначать.
2. **Billing → ваш платёжный аккаунт → Access bindings → Assign roles**: выбрать этот сервисный аккаунт и роль
   `billing.accounts.viewer`.
3. Открыть сервисный аккаунт → **Create new key → Create authorized key** (алгоритм по умолчанию), **Create** → скачать JSON.
4. Передать ключ агенту через `bb secret request` (значение агенту не видно, пишется в файл с правами 600) — агент откроет форму,
   когда вы у экрана.

Роль выдаётся на платёжный аккаунт, а не на облако или каталог: так аккаунт не видит ни ваши модели, ни данные.
Отозвать — удалить сервисный аккаунт в консоли.
