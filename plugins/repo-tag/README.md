# Repo tags_vibecom 0.1.0

Last Updated: 2026-10-21

Папка и id плагина — `repo-tag`; в интерфейсе BB он называется Repo tags_vibecom.
В строке каждого треда в боковой панели, сразу после иконки модели, — тег из первых букв репозитория
(проекта bb) в своём цвете: видно, где работает тред, даже без группировки по проектам. Суффикс `_code`
отбрасывается: `shop_code` → `sho`. У треда без проекта тега нет. BB >= 0.46, SDK >= 0.6.37.

Установка из Git:

```sh
bb plugin install "git:https://github.com/vibe-commerce-org/bb-vadim-setup.git@semver:~0.4.0" --subdirectory plugins/repo-tag
```

Локально, в этой папке: npm ci, bb plugin build ., bb plugin install .
Тесты: npm test (Node.js >= 22.18) — тексты тегов, раздача цветов, контраст WCAG AA в обеих темах,
вставка в разметку списка тредов.

Длина тега — `bb plugin config repo-tag set tagLength 6` (2–16, по умолчанию 3) и
`compactTagLength` для окна уже 768 px. Меняется сразу, без перезагрузки. Репозитории с одинаковым
началом различаются цветом. Плагин дописывает тег в разметку встроенного списка тредов
(`.bb-thread-title` — внутренняя разметка bb 0.46): если после обновления bb теги пропали, строки
работают как раньше, а `tests/bb-markup.test.ts` покажет, что изменилось.
