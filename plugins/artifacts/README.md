# Важные артефакты_vibecom 0.1.0 — бета

Last Updated: 2026-10-21

Папка и id плагина — `artifacts`; в интерфейсе BB он называется Важные артефакты_vibecom.
Постоянная вкладка «Важные артефакты» в правой панели треда: бриф, план, статус, handoff, нужные файлы
и HTTP(S)-ссылки, привязанные к этому треду, с закреплением, порядком и архивом. Сообщения треда не
меняются. BB >= 0.46, SDK >= 0.6.37.

**Бета — что пока не работает:**

- панель не открывается сама при входе в тред: откройте её кнопкой-закладкой в заголовке треда, через `+`
  в правой панели или командой «Важные артефакты: открыть справа» (автопоказа в стабильном SDK bb нет);
- список не наполняется сам: агент добавляет записи командой `bb artifacts add`, а пустая панель только
  предлагает найденные брифы, планы и статусы кнопкой «Добавить»;
- открытие файлов и кнопка в заголовке опираются на экспериментальную часть SDK bb: после обновления bb
  проверьте их заново; вид на телефоне вживую не проверялся.

Установка из Git:

```sh
bb plugin install "git:https://github.com/vibe-commerce-org/bb-vadim-setup.git@semver:~0.5.0" --subdirectory plugins/artifacts
```

Локально, в этой папке: npm ci, bb plugin build ., bb plugin install .
Тесты: npm test (Node.js >= 22.18) — модель, SQLite-хранилище, панель в jsdom.

Команды агента (только для текущего треда): `bb artifacts list`, `add --title … (--file путь | --url https://…)`,
`update`, `pin`, `archive`, `restore`, `remove`, `suggest` — `skills/artifacts/SKILL.md`.
В базе плагина лежат только ссылки и подписи, не содержимое файлов; ссылки — только `http:`/`https:` без
логина и пароля в адресе. Внешние страницы открываются браузером bb, без iframe и скриптов.
До 200 записей на тред.
