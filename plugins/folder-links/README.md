# Folder links_vibecom 0.4.0

Last Updated: 2026-10-21

Папка и id плагина — `folder-links`; в интерфейсе BB он называется Folder links_vibecom.
Ссылка на папку в сообщении открывает дерево справа. BB >= 0.44, SDK >= 0.5.9.
Отсутствующая папка подменяется существующим предком с пояснением. Ссылки на файлы обрабатывает BB.

Что плагин читает: домашнюю папку сервера bb, в WSL2 — ещё профиль Windows (`/mnt/c/Users/<имя>`),
и с 0.4.0 — папки всех проектов bb на этом компьютере. Репозиторий на `C:\dev`, `D:\work` или внешнем
диске открывается сам, без настроек: список проектов плагин перечитывает каждые 10 секунд. Соседи и
родители папки проекта, корень диска и папка, внутри которой лежит домашняя, остаются за BB.

Установка из Git:

```sh
bb plugin install "git:https://github.com/vibe-commerce-org/bb-vadim-setup.git@semver:~0.5.0" --subdirectory plugins/folder-links
```

Локально, в этой папке: npm ci, bb plugin build ., bb plugin install .
Тесты: npm test (Node.js >= 22.18) — пути macOS, Linux, WSL2 и Windows на поддельных дисках, корни проектов.

| Где работает сервер bb | Как работает плагин | Чем проверено |
|---|---|---|
| macOS | пути `/Users/…`, папки проектов bb | вживую, bb 0.46.1 |
| Linux, Ubuntu | пути `/home/…`, регистр имён важен | тестами |
| Windows через WSL2 | как Linux, плюс профиль Windows `/mnt/c/Users/<имя>` | тестами |
| Windows (alpha) | `C:\…`, `C:/…`, `file:///C:/…`; сетевые `\\сервер\папка` — нет | тестами |

На Windows ссылку на папку агент пишет как `file:///C:/Users/Имя/папка`: путь вида `C:\…` без точки
в последнем имени bb 0.46 показывает простым текстом. Правила путей выбирает сервер bb, а не браузер:
с телефона в bb на Mac действуют правила Mac. Плагин опирается на внутренние селекторы чата BB:
после обновления BB проверьте ссылку на папку.
