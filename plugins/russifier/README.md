# Русификатор_vibecom 0.2.0

Last Updated: 2026-10-21

Папка и id плагина — `russifier`; в интерфейсе BB он называется Русификатор_vibecom.
Переводит интерфейс bb на русский по словарю: подписи, меню, подсказки, ленту действий агента,
встроенные плагины, Explorer_vibecom и Terminal_vibecom. Переписку, код, поле ввода, названия чатов,
проектов и файлов не трогает. Работает в приложении и в браузере телефона. BB >= 0.46, SDK >= 0.6.37.

По-английски остаётся то, что так видно в документации, интерфейсе провайдера и командах: effort и его
уровни (Low … Max, Ultracode), режимы доступа (Full Access, Accept Edits, Approve for me, Plan Mode),
Fast mode, названия продуктов, моделей и команд. Список — раздел «Не переводим» в `GLOSSARY.md`.

Установка из Git:

```sh
bb plugin install "git:https://github.com/vibe-commerce-org/bb-vadim-setup.git@semver:~0.5.0" --subdirectory plugins/russifier
```

Локально, в этой папке: npm ci, bb plugin build ., bb plugin install .
Тесты: npm test (Node.js >= 22.18) — движок перевода, страница в jsdom (переписка не меняется,
откат без перезагрузки), effort и приоритеты задач на настоящих словарях.

- Вернуть английский: Settings → Plugins → Русификатор_vibecom → «Язык интерфейса» → English,
  или `bb plugin config russifier set language en`. Только на одном устройстве — команда
  «Язык интерфейса: русский ↔ English» в поиске команд (⌘⇧P).
- Что ещё не переведено: `bb russifier missing`. Свои правки держите в `dict/extra.json` — он главнее
  остальных словарей.
- Поиск команд ищет по английским названиям; меню macOS и системные уведомления остаются английскими.
- Словарь собран по bb 0.46.0. После обновления bb новые подписи остаются английскими, пока их не
  добавят в словарь (`skills/russifier/SKILL.md`, раздел «Обновление словаря»).
