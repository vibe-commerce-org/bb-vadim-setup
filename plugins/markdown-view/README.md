# Markdown_vibecom 0.4.0

Last Updated: 2026-10-11

Папка и id плагина — `markdown-view`; в интерфейсе BB он называется Markdown_vibecom.
Открывает .md/.mdx/.markdown только для чтения в виде Typora (движок Vditor):
ссылки, таблицы, метки заголовков, оглавление, картинки по относительным путям.
Файл изменился на диске — вид обновляется сам. Цвета берутся из темы BB.
Кнопка «Редактировать» включает правку Vditor: «Как в Typora», «Как в Word»,
«Исходник». На телефоне панель инструментов — одна строка с прокруткой пальцем.
Зависимости и SDK закреплены в package.json и package-lock.json. BB >= 0.43, SDK >= 0.5.9.

Установка из Git:

```sh
bb plugin install "git:https://github.com/vibe-commerce-org/bb-vadim-setup.git@semver:~0.4.0" --subdirectory plugins/markdown-view
```

Локально, в этой папке: npm ci, bb plugin build ., bb plugin install .
Тесты: npm test (Node.js >= 22.18; проверено на 25.2.1) — сохранение, пути
чтения, ссылки, разбор Lute, касания панели на iPhone, состав пакета `src/`.
Папка `src/` — ещё и пакет `@vibecommerce/markdown-view`: из него Explorer_vibecom
показывает Markdown у себя в панели (архив в `plugins/files-editor/vendor/`).
Не удаляйте node_modules после сборки: сервер отдаёт оттуда Vditor.

Изменения в основном сохраняются по строкам. Если результат нормализации
не совпал, возможно полное форматирование документа с отметкой редактора.
Проверяйте diff. При конфликте версий выбирайте нужную версию явно.
Правленые строки Vditor пишет в своём формате: неразрывные пробелы в них
становятся обычными. Настройки вида сохраняются в браузере.

Относительные картинки грузятся через временную раздачу папки BB
(`sdk.files.createPreview`): картинка выше корня проекта или папки файла
не покажется. Адрес без `[текст](…)` и `<…>` ссылкой не становится.
Вставка картинок из буфера не настроена.
