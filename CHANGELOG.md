## [0.4.1] — 2026-10-21

### Исправлено

- Грант Cloud.ru: по правилам акции «4000 бонусных баллов…» он не тратится на Foundation Models, то есть на
  GLM и Kimi; модели оплачиваются рублями по токенам. Исправлено в сравнении путей и шаге 2 Cloud.ru
  (`GUIDE.md`, начало части 2 и раздел 6) и в пункте `models-cloudru` каталога. Совет «начните с пути 2» теперь про Яндекс:
  там стартовый грант на модели тратится.
- Свои плагины — 0.4.1, код тот же, что в 0.4.0.

## [0.4.0] — 2026-10-21

### Добавлено

- Четыре плагина: **Русификатор_vibecom** 0.2.0 — интерфейс bb на русском; **Repo tags_vibecom** 0.1.0 —
  тег репозитория у каждого треда в боковой панели; **Пульт_vibecom** 0.2.0 — какие треды ждут вас,
  приоритеты задач Сейчас / Дальше / Потом, карта проектов; **Важные артефакты_vibecom** 0.1.0 (бета) —
  бриф, план и важные файлы треда во вкладке справа. Всем четырём нужен bb 0.46+.
- Русификатор: по-английски остаётся то, что так видно в документации, интерфейсе провайдера и командах —
  effort и его уровни (Low … Max, Ultracode) в меню модели и на кнопке у поля ввода, режимы доступа (Full Access,
  Accept Edits, Approve for me, Plan Mode), Fast mode, названия продуктов и моделей. Список — раздел
  «Не переводим» в `plugins/russifier/GLOSSARY.md`. Приоритеты задач Low / Medium / High остаются русскими.
- Гайд: блок «Поставить bb вручную, без скриптов» в начале части 1 — прямые ссылки на установщики (зеркало
  курса, getbb.app, GitHub Releases), SHA-256, что делать дальше на Mac и Windows; на Windows — честное
  сравнение приложения (alpha) и WSL2. Номера и якоря разделов 2–4 прежние.
- `catalog.json`: наборы `presets` («Главное», «Расширенное», «Всё как у Вадима»), у пунктов — `tier` и
  `short`; сайт берёт их из выпуска, а не из черновика. Поле `"stage": "beta"` — у Артефактов.
- `AGENT-TASK.md`: модель без ключа — шаблон и подсказка, куда вписать ключ, без остановки; LM Studio —
  отдельный вопрос перед скачиванием модели.
- Шаблон правил `instructions/AGENTS.md`: строка «⏸ Ход за тобой» в конце ответа (её читает Пульт), команды
  родителя дочернему треду, вопросы дочерних тредов одним списком, название треда на языке пользователя.

### Изменено

- Модели (Яндекс, Cloud.ru, LM Studio) отмечены по умолчанию и входят в набор «Главное».
- Folder links_vibecom 0.4.0: кроме домашней папки читает профиль Windows в WSL2 и папки всех проектов bb на
  этом компьютере — репозиторий на `C:\dev`, `D:\work` или внешнем диске открывается без настроек.
  Тесты — 56.
- Пульт в комплекте: маркер конца хода принимает любое слово после «Ход за» («Ход за тобой»), комментарии и
  тестовые данные обезличены.
- Диапазон установки из Git — `@semver:~0.4.0`; плагины, поставленные с `~0.3.0`, переустановите.
- Скрипты выпуска берут список плагинов из папки `plugins/`; `sync-plugins.py` переносит и новые плагины,
  а плагин без коммитов в источнике пропускает.
- Снимок настроек Вадима (гайд, раздел 17) — на 21.10, bb 0.46.1.

## [0.3.5] — 2026-10-14

### Добавлено

- Folder links_vibecom понимает пути Windows: `C:\…`, `C:/…`, `file:///C:/…` с кириллицей
  и пробелами, разделители вперемешку, домашняя папка — `%USERPROFILE%`. Сетевые пути
  `\\сервер\папка` не поддерживаются. Проверено тестами (26), на живой Windows не испытано.
  На Windows ссылку на папку агент пишет как `file:///C:/…`: путь `C:\…` bb 0.46 показывает
  простым текстом.
- Explorer_vibecom сам закрепляет «Built-in preview» за `.html` и `.htm` при первой загрузке
  bb на устройстве, если вы ничего не выбирали; ручной шаг в гайде остался запасным.
  Тесты Explorer_vibecom — 393.

### Удалено

- Группировка списка тредов по проектам больше не входит в рекомендации: пункт
  `settings-thread-list` убран из каталога, задания агенту и раздела 8 гайда.

### Изменено

- Свои плагины — версия 0.3.5.

- Свои плагины — версия 0.3.4, их код не менялся.

## [0.3.3] — 2026-10-13

### Добавлено

- `catalog.json` — каталог пунктов комплекта (тема, плагины, инструкции, настройки,
  модели) и двух промптов установки: «bb уже есть» и «есть Codex или Claude Code».
  По нему сайт строит страницу выбора; файл входит в выпуск отдельно.
- `AGENT-TASK.md`: выборочная установка по спискам «Поставить» и «Не ставить» (раздел
  «Пункты комплекта») и раздел «Если ты агент вне bb»: агент в обычном терминале ставит
  bb, а настройку передаёт агенту внутри bb готовым промптом.
- `scripts/check-kit.py` сверяет каталог с `AGENT-TASK.md`, плагинами, версиями и
  якорями гайда; `scripts/build-kit.py` сам проставляет в каталог версию, тег и адреса.

### Изменено

- Общие настройки в `AGENT-TASK.md` разбиты по пунктам каталога; переназначение клавиш
  Вадима — отдельный пункт `settings-hotkeys`.
- Свои плагины — версия 0.3.3, код не менялся.

## [0.3.0] — 2026-10-11

Комплект студентов «bb как у Вадима» (`08-BB-VADIM-KIT.zip`) и этот репозиторий
объединены: теперь это один комплект, и архив, инструкция и файл для агента
собираются отсюда. Плагины с диапазоном `~0.2.0` на 0.3.0 сами не обновятся —
переустановите их с `@semver:~0.3.0`.

### Добавлено

- `AGENT-TASK.md` — задание кодинговому агенту: настроить bb по комплекту с
  профилями macOS, Linux-сервера и Windows.
- `models/pi/` — шаблоны агента Pi для моделей Яндекса, Cloud.ru и LM Studio, без ключей.
- `scripts/` — сборка выпуска (`build-kit.py`: ZIP с папкой `bb-vadim-kit/`,
  `08-BB-VADIM-SETUP.md`, файл для агента со встроенным ZIP), проверки
  (`check-kit.py`, `test-plugins.sh`, `check-git-install.sh`), перенос плагинов
  из рабочего репозитория (`sync-plugins.py`) и `extract-kit.mjs`. В комплект не входят.

### Изменено

- `GUIDE.md` — инструкция комплекта студентов вместо прежней: установка bb на
  macOS, Windows и Linux-сервер, подключение моделей (подписка, российские облака
  через Pi, локальные), настройка, телефон, проверка и частые ошибки. Из прежней
  инструкции перенесены установка плагинов из Git, обновление и откат, имя темы
  `atom-one_vibecom` и описание Explorer_vibecom.
- `instructions/AGENTS.md` — девять разделов вместо семи: добавлены «Контекст
  треда» (бриф с решениями пользователя, сохранение статуса до сжатия контекста)
  и «Терминал».
- `examples/demo.md` — кнопки «Редактировать» и «Готово», раздел со ссылками.
- Свои плагины — версия 0.3.0 (код не менялся). Установка из папки: у Explorer_vibecom
  и Terminal_vibecom — `npm ci --ignore-scripts`.
- `MANIFEST.json` — формат 3: добавлены внешний плагин File Manager и шаблоны
  моделей; служебные `scripts/` и `.gitignore` в манифест не входят.
- В `release/` — `08-BB-VADIM-KIT.zip`, `08-BB-VADIM-SETUP.md`, `08-BB-AGENT-SETUP.md`
  вместо `bb-vadim-setup-vX.Y.Z.zip`.

### Исправлено

- Explorer_vibecom больше не забирает курсор из поля ввода треда, терминала и
  других полей, когда появляется сам: по ⌘J, по ссылке на файл из чата, после
  перезагрузки bb или плагина. Тесты Explorer_vibecom — 373.

## [0.2.0] — 2026-10-11

В комплекте пять плагинов: к трём своим добавлены Explorer_vibecom и
Terminal_vibecom. Плагины и тема получили имена с суффиксом `_vibecom`.
Плагины из 0.1.0 с диапазоном `~0.1.0` на 0.2.0 сами не обновятся —
переустановите их с `@semver:~0.2.0` (README, «Обновление и откат»).

### Добавлено

- Explorer_vibecom 0.1.6 (`plugins/files-editor`) — проводник и редактор
  рабочей копии: дерево проекта и домашней папки, сортировка, поиск по именам и
  тексту, меню файла, операции с файлами с корзиной и отменой, загрузка и
  скачивание, PDF, Word, Excel, PowerPoint и Markdown внутри панели, защита
  секретных файлов. Переделка abdoutelb/bb-plugin-files-editor v0.1.6 с кодом
  загрузки из file-manager (xMinor-1/bb-plugins). Ставится из Git: просмотрщики
  лежат в `vendor/` архивами пакетов. Для `.md` нужен установленный Markdown_vibecom.
- Terminal_vibecom 0.6.2 (`plugins/floating-terminal`) — терминал вкладкой в
  правой панели треда и плавающим окном; вставка на iPhone, многострочная
  вставка без выполнения, новый терминал не портит текст в остальных.
  Переделка vburojevic/bb-plugin-floating-terminal v0.5.3.
- Папки `src/` Markdown_vibecom и Office_vibecom — пакеты
  `@vibecommerce/markdown-view` и `@vibecommerce/office-preview` (в npm не
  публикуются); из них Explorer_vibecom показывает документы.
- Тесты: Markdown_vibecom — 28, Office_vibecom — 10, Explorer_vibecom — 366,
  Terminal_vibecom — 86.
- В THIRD_PARTY_NOTICES — полные тексты лицензий MIT авторов переделанных
  плагинов и шрифта Nerd Fonts.

### Изменено

- Видимые имена плагинов: Markdown_vibecom, Office_vibecom, Folder links_vibecom.
  Id, папки и имена пакетов прежние: `markdown-view`, `office-preview`, `folder-links`.
- Тема `atom-one` переименована в `atom-one_vibecom`: новая папка и
  `bb theme set atom-one_vibecom`. Файлы темы не изменились.
- Markdown_vibecom 0.2.0: файл открывается только для чтения в виде Typora
  (Vditor): ссылки, таблицы, метки заголовков, относительные картинки, цвета из
  темы BB. Правка — по кнопке «Редактировать». На телефоне панель инструментов —
  одна строка с прокруткой. Открыватель называется «Markdown (как в Typora, правка)».
  SDK для сборки — 0.6.15.
- Office_vibecom 0.2.0: компоненты просмотра вынесены в `src/openers.tsx`,
  контракт RPC — в `src/rpc.ts`. SDK для сборки — 0.6.15.
- Folder links_vibecom 0.2.0: изменилось только имя.
- GUIDE, раздел 5: вместо сторонних File Manager и Files editor — Explorer_vibecom.
- Версия трёх своих плагинов в `package.json` и корне `package-lock.json` равна
  версии комплекта; их зависимости рабочей установки не изменились.

### Исправлено

- Markdown_vibecom и Office_vibecom читают файлы через `sdk.files` вместо
  внутренних адресов BB: в BB 0.45 эти адреса сменились, и чтение в 0.1.0
  перестало работать. Файлы хранилища треда Markdown_vibecom находит через
  SDK и больше не ограничивает их просмотром.
